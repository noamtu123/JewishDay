Screenshots for F-Droid go in this folder. Noam takes them on his phone and adds them by hand.

- Name them `1.png`, `2.png`, `3.png`, … in the order they should appear (PNG or JPEG;
  `.png`, `.jpg` or `.jpeg`). F-Droid sorts by file name, so past nine use `01.png`, `02.png`, …
  from the start.
- Full-screen portrait captures straight from the phone, no frames or captions.
- Screenshots in this `en-US` folder are the default for every language. For Hebrew ones, put the
  same names in `../../../he/images/phoneScreenshots/`.
- F-Droid strips metadata and may recompress, so keep them reasonably small (under ~1 MB each).

This README is not an image, so F-Droid ignores it.
